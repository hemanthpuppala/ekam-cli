# Vision Object Detection Test Images

Place 20 test images in this folder for Vision Object Detection benchmarking.

## File Naming Convention

Images should be named sequentially:
- `img_01.jpg` through `img_20.jpg`

## Image Requirements

- Format: JPG, PNG, or other common image formats
- Content: Images with multiple detectable objects suitable for object detection tasks
- Each image will be paired with the corresponding VLM_DETECT_PROMPTS from defaults.py

## Usage

These images are used when "Default" test data is selected for VLM Detect endpoint benchmarking.
