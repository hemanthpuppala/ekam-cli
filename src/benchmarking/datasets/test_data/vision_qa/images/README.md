# Vision QA Test Images

Place 20 test images in this folder for Vision Q&A benchmarking.

## File Naming Convention

Images should be named sequentially:
- `img_01.jpg` through `img_20.jpg`

## Image Requirements

- Format: JPG, PNG, or other common image formats
- Content: Diverse images suitable for visual question-answering tasks
- Each image will be paired with the corresponding VLM_VISION_QA_PROMPTS from defaults.py

## Usage

These images are used when "Default" test data is selected for VLM Vision Q&A endpoint benchmarking.
